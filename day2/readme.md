The objective of Day 2 was to understand the fundamentals of Python programming and apply them through basic practice programs and small projects.

- Functions
- Basic Python Syntax

## 📚 What I Learned

### Variables

Variables are used to store values in a Python program.



I learned how to create variables, assign values, and use them in programs.

Data Types

I practiced commonly used Python data types:

int
float
str
bool
list
tuple
dict
set
Conditional Statements

I learned how to use:

if
elif
else

These statements allow a program to make decisions based on conditions.

Loops

I practiced:

for loops
while loops

Loops are useful for repeating a block of code multiple times.

Functions

I learned how to create reusable blocks of code using functions.

Example:

def add(a, b):
    return a + b

Functions help make programs more organized and reusable.
